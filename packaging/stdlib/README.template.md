# DFD-PlantUML preview contribution

This generated candidate is not included in an official PlantUML release.
The preview version and release metadata require review before submission.
Canonical sources and update instructions are maintained in the source repository.
Regenerate this directory from the committed source; do not edit exported files.

Use `@startdot` / `@enddot`, Graphviz, and either
`!include <dfd/DFD_Level_0>` or `!include <dfd/DFD_Level_1>`.
For native SVG, the tested engine requires the UNSECURE security profile.
See `_examples_` for executable examples. The Level 0 `Process(alias, label, id)`
and Level 1 `Process(label)` calls retain their distinct published meanings.

The complete MIT license is retained as comments in each exported PlantUML file.
